# Fonts

The pages of the site use two free fonts. Both have the SIL Open Font License 1.1 (see the `OFL-*.txt`
files). The font files are in this folder, thus the page loads no file from an other site.

| Family | Role | Files |
| --- | --- | --- |
| Barlow Condensed | All text. Headlines are weight 800 or 900 italic, in capitals | `BarlowCondensed-400.woff2`, `-500`, `-700`, `-800`, `-800i`, `-900i` |
| JetBrains Mono | Numbers, file names, the console | `JetBrainsMono.woff2` (weights 400 to 700 in one file) |

The fonts are declared with `@font-face` at the top of `../css/colors_and_type.css`, and for the
Screen Designer at the top of `../designer/index.html`.
